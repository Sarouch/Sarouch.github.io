# Publish your portfolio on GitHub Pages

## 1. Personalize the files
Open `index.html` and replace:
- `YOUR NAME`
- `YOUR-USERNAME`
- `YOUR-EMAIL@example.com`
- Generic project descriptions and example links

Update `README.md` with your verified projects, tools, publications, and contact links. Do not publish confidential laboratory data or code.

## 2. Create a GitHub repository
1. Sign in at https://github.com/
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `README.md`, and this guide (you can omit the guide from the public site if you prefer).
4. Commit the files.

## 3. Open the website
Your site should be available at `https://YOUR-USERNAME.github.io/`. GitHub Pages may take a few minutes to publish.

## 4. Optional: use this as a project repository instead
If you want a repository called `portfolio`, upload `README.md` to it. To publish the HTML site from a normal repository, go to **Settings → Pages**, choose the deployment source and branch, and save.

## Before publishing
- Verify every claim and result.
- Replace all placeholders.
- Add a PDF CV only if you want it public.
- Use project images only when you have permission to share them.
- Keep private email/phone/address details out of public repositories.
